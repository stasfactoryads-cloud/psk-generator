# Генератор планировок ПСК

Одностраничное приложение (GitHub Pages). Открывает `index.html`, загружает каталог лотов из публичного фида ГК ПСК и показывает лоты с планировками.

- Источник: `https://raw.githubusercontent.com/stasfactoryads-cloud/psk-official-data/main/api/flats.json`
- Фильтры: проект, комнаты, статус, цена, площадь, сортировка.
- Карточка лота открывает планировку квартиры и план этажа.

Сборка не нужна: страница статическая, без внешних библиотек.
